# News-Lens-AI-Powered-Personalized-News-Aggregator

News Lens: AI-Powered Personalized News Aggregator
Overview

News Lens is an AI-powered news aggregation platform that helps users identify fake news and access trustworthy information. The system collects real-time news articles, analyzes their content using Natural Language Processing (NLP) and Machine Learning techniques, performs fact-checking, and provides personalized news recommendations.

Problem Statement

With the rapid growth of social media and online news platforms, misinformation and fake news spread quickly. Traditional fake news detection systems often focus only on headlines and lack real-time verification, resulting in inaccurate predictions.

Proposed Solution

News Lens analyzes complete news articles, verifies information using trusted sources, and classifies news as Real, Fake, or Uncertain. The system also recommends relevant and reliable news articles based on user interests.

System Workflow
Fetch news articles using GNews API.
Extract complete article content using BeautifulSoup.
Preprocess text using NLP techniques.
Classify news using a BERT-based model.
Perform fact-checking by comparing content with trusted sources.
Generate a final prediction using a hybrid decision engine.
Recommend relevant and trustworthy news articles to users.
